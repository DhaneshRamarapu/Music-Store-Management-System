 Music Store Data Analysis using SQL

 Project Overview

This project focuses on building a **Music Store Management System** using SQL to organize, manage, and analyze data efficiently. It demonstrates how relational databases can transform raw data into meaningful insights for better decision-making.

---

 Objectives

* Design a structured relational database
* Analyze customer behavior and purchasing patterns
* Evaluate sales performance across regions and genres
* Improve decision-making using data insights
* Reduce manual work and increase efficiency

---

 Database Structure

The database consists of interconnected tables:

* Customer
* Employee
* Artist & Album
* Track & Genre
* Invoice & Invoice Line
* Playlist & Playlist Track

These tables are linked using **primary and foreign keys** to ensure data integrity.

---

 Key SQL Queries

This project answers important business questions such as:

* Senior-most employee
* Countries with the most invoices
* Best customer based on spending
* Rock music listeners
* Top 10 rock artists
* Tracks longer than average
* Customer spending per artist
* Most popular genre per country
* Top customer per country

---

 Key Insights

* USA generates the highest revenue and invoices
* Rock is the most popular genre
* Top customers contribute significantly to sales
* Certain cities outperform others in revenue

---

 Conclusion

This project shows how SQL efficiently manages large datasets and enables fast analysis to uncover customer trends and preferences, supporting better data-driven decisions.
